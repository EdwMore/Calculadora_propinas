# 💰 Calculadora de Propinas

Aplicación desarrollada con React + Vite que permite calcular propinas de forma dinámica y actualizar automáticamente el total.

Este proyecto fue construido con el objetivo de practicar conceptos modernos del ecosistema React, aplicando buenas prácticas de separación de responsabilidades, reutilización de lógica y tipado estático.

---

## 🚀 Demo

https://rainbow-brioche-8d72b0.netlify.app/
---

## 🧠 Objetivos de aprendizaje

Durante el desarrollo trabajé y reforcé conceptos como:

- Creación de aplicaciones con **React + Vite**
- Desarrollo con **TypeScript** para mejorar el tipado y mantenimiento
- Uso de **Hooks personalizados** para encapsular lógica reutilizable
- Arquitectura basada en **componentes reutilizables**
- Simulación de una **fuente de datos local**
- Estilizado utilizando **Tailwind CSS**

---

## 🧩 Conceptos aplicados


### Hooks personalizados

Se encapsuló lógica de negocio dentro de hooks personalizados para mejorar reutilización y legibilidad.

### TypeScript

Se definieron tipos e interfaces para reducir errores y hacer el código más mantenible.

### Simulación de base de datos

Se creó una capa de datos local para representar un flujo similar al consumo de datos externos.

## ▶️ Instalación

Clona el repositorio:

```bash
git clone https://github.com/EdwMore/Calculadora_propinas.git
```

Instala dependencias:

```bash
npm install
```

Ejecuta el proyecto:

```bash
npm run dev
```
